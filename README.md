# Pingback Buddy

A webhook listener and dashboard for payment gateway notifications (pingbacks).

Built to capture, log, and display real-time payment events from gateways like Hotmart, Kiwify, and others.

## Stack
- React + TypeScript + Vite
- Supabase (database + edge functions)
- Tailwind CSS + shadcn/ui
- Deployed on Vercel
